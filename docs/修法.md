# 每一種問題怎麼修

[English](fixes.md)

一種一節：長什麼樣子、改成怎樣。為什麼算問題、依據哪一條在 [標準對照.md](標準對照.md)；WPF 實際怎麼做是量的（[WPF實測.md](WPF實測.md)）。

## missing-name

只有圖示的控制項。ToolTip 不是名稱。

```xml
<!-- 原本 -->
<Button ToolTip="刪除"><Path Data="{StaticResource TrashIcon}"/></Button>
<!-- 改成 -->
<Button ToolTip="刪除" AutomationProperties.Name="刪除"><Path Data="{StaticResource TrashIcon}"/></Button>
```

圖示按鈕很多、都有 ToolTip：一個樣式就能拿它當名稱。

```xml
<Style TargetType="Button" x:Key="IconButton">
  <Setter Property="AutomationProperties.Name" Value="{Binding ToolTip, RelativeSource={RelativeSource Self}}"/>
</Style>
```

每一列都有的控制項：名稱用綁定的，不然每一列念起來都一樣。

```xml
<CheckBox IsChecked="{Binding Notify}" AutomationProperties.Name="{Binding FolderLabel, StringFormat=通知：{0}}"/>
```

停用的 Button 只是拿來當文字旁邊的圖：不要給名稱（同一句會念兩次）。改用 `Path` 或 `Image`，或寫理由壓掉。

微軟的說明：[按鈕的名稱](https://learn.microsoft.com/en-us/accessibility-tools-docs/items/wpf/button_name)。

## text-not-in-name

字在面板裡面，WPF 只從字串、`TextBlock`、`ContentControl` 拿名稱。

```xml
<!-- 原本 -->
<Button><StackPanel Orientation="Horizontal"><Image Source="save.png"/><TextBlock Text="儲存"/></StackPanel></Button>
<!-- 改成 -->
<Button AutomationProperties.Name="儲存"><StackPanel Orientation="Horizontal"><Image Source="save.png"/><TextBlock Text="儲存"/></StackPanel></Button>
```

字是綁定的，名稱就綁同一個屬性。

## meaningless-name

```xml
<!-- 原本：NVDA 念不出來，或念「System dot Windows dot Controls dot Tab Item」 -->
<Button FontFamily="Segoe MDL2 Assets" Content="&#xE74D;"/>
<TabItem><TabItem.Header><Image Source="home.png"/></TabItem.Header></TabItem>
<!-- 改成 -->
<Button FontFamily="Segoe MDL2 Assets" Content="&#xE74D;" AutomationProperties.Name="刪除"/>
<TabItem AutomationProperties.Name="首頁"><TabItem.Header><Image Source="home.png"/></TabItem.Header></TabItem>
```

連結的內容是元素、不是文字：

```xml
<TextBlock><Hyperlink Command="{Binding Open}"><InlineUIContainer><TextBlock Text="{Binding Title}"/></InlineUIContainer></Hyperlink></TextBlock>
<!-- 其中一種 -->
<TextBlock><Hyperlink Command="{Binding Open}"><Run Text="{Binding Title, Mode=OneWay}"/></Hyperlink></TextBlock>
<!-- 或 -->
<TextBlock><Hyperlink Command="{Binding Open}" AutomationProperties.Name="{Binding Title}"><InlineUIContainer><TextBlock Text="{Binding Title}"/></InlineUIContainer></Hyperlink></TextBlock>
```

`Mode=OneWay` 不能省：`Run.Text` 預設是 TwoWay，綁到唯讀屬性會丟例外。

## input-no-name

`Label.Target` 只會用快速鍵移焦點。把標籤接成欄位的名稱。

```xml
<!-- 原本 -->
<Label Content="姓名(_N)" Target="{Binding ElementName=NameBox}"/>
<TextBox x:Name="NameBox"/>
<!-- 改成 -->
<Label x:Name="NameLabel" Content="姓名(_N)" Target="{Binding ElementName=NameBox}"/>
<TextBox x:Name="NameBox" AutomationProperties.LabeledBy="{Binding ElementName=NameLabel}"/>
```

畫面上沒有標籤（搜尋框）：`AutomationProperties.Name="搜尋"`。
微軟的說明：[輸入框](https://learn.microsoft.com/en-us/accessibility-tools-docs/items/wpf/edit_name)、
[下拉式方塊](https://learn.microsoft.com/en-us/accessibility-tools-docs/items/wpf/combobox_name)。

## list-no-name

```xml
<!-- 原本 -->
<TextBlock Text="檔案"/><ListBox ItemsSource="{Binding Files}"/>
<!-- 改成 -->
<TextBlock x:Name="FilesLabel" Text="檔案"/>
<ListBox ItemsSource="{Binding Files}" AutomationProperties.LabeledBy="{Binding ElementName=FilesLabel}"/>
```

## widget-no-name

`ProgressBar`、`Calendar`、`Menu`、`ToolBar` 一樣（`ToolBar.Header` 寫字串也算名稱）。

## item-type-name

資料產生的項目，名稱是 `ToString()`。沒覆寫的類別，每一項都念成 `MyApp.Models.Note`，設了 `DisplayMemberPath` 也一樣。

最簡單，這個類別的每個清單一次好：

```csharp
public override string ToString() => Title;
```

或在某個清單的項目樣式裡：

```xml
<!-- 原本 -->
<ListBox ItemsSource="{Binding Notes}" DisplayMemberPath="Title"/>
<!-- 改成 -->
<ListBox ItemsSource="{Binding Notes}" DisplayMemberPath="Title">
  <ListBox.ItemContainerStyle>
    <Style TargetType="ListBoxItem"><Setter Property="AutomationProperties.Name" Value="{Binding Title}"/></Style>
  </ListBox.ItemContainerStyle>
</ListBox>
```

用樣式要注意：

- 清單（或清單的樣式）**已經有 `ItemContainerStyle`**（`DataGrid` 是 `RowStyle`）的，把 Setter 加進那一個。再寫一個會整個取代，清單的樣子就沒了。
- 項目的樣子是佈景給的，要接著它：`BasedOn="{StaticResource {x:Type ListBoxItem}}"`。有 `GridView` 的 `ListView` 是
  `BasedOn="{StaticResource {x:Static GridView.GridViewItemContainerStyleKey}}"`。
- 容器是 `ListViewItem`、`ComboBoxItem`、`TreeViewItem`、`TabItem`、`MenuItem`、`DataGridRow`。
- 收起來的 `ComboBox` 念選到的那一項也是這樣（NVDA 實跑），不是只有展開才念錯。兩種修法都有用。

## silent-tab-stop

`ContentControl` 與 `Control` 預設就拿得到鍵盤焦點，又沒有 AutomationPeer。

```xml
<!-- 原本 -->
<ContentControl Content="{Binding CurrentPage}"/>
<!-- 改成：它只是放別的控制項 -->
<ContentControl Content="{Binding CurrentPage}" Focusable="False"/>
```

程式會對它呼叫 `Focus()` 的（例如換頁之後），改用 `IsTabStop="False"`。

自己寫的、要讓人操作的控制項，給它 peer（或改成繼承 `Button`，它有）：

```csharp
protected override AutomationPeer OnCreateAutomationPeer() => new CardAutomationPeer(this);

sealed class CardAutomationPeer(Card owner) : FrameworkElementAutomationPeer(owner), IInvokeProvider
{
    protected override AutomationControlType GetAutomationControlTypeCore() => AutomationControlType.Button;
    protected override string GetClassNameCore() => nameof(Card);
    public override object? GetPattern(PatternInterface pattern) => pattern == PatternInterface.Invoke ? this : base.GetPattern(pattern);
    public void Invoke() => ((Card)Owner).Open();
}
```

```xml
<Button Content="×"/>

```

## same-name

```xml
<!-- 原本 -->
<Button Content="瀏覽…" Command="{Binding BrowseInput}"/>
<Button Content="瀏覽…" Command="{Binding BrowseOutput}"/>
<!-- 改成 -->
<Button Content="瀏覽…" AutomationProperties.Name="瀏覽輸入資料夾" Command="{Binding BrowseInput}"/>
<Button Content="瀏覽…" AutomationProperties.Name="瀏覽輸出資料夾" Command="{Binding BrowseOutput}"/>
```

名稱要以畫面上的字開頭，用說的操作才叫得到它（2.5.3）。

## mouse-only

```xml
<!-- 原本 -->
<Border MouseLeftButtonUp="OnOpen"><TextBlock Text="開啟"/></Border>
<!-- 改成：看起來不像按鈕的按鈕 -->
<Button Click="OnOpen" Content="開啟">
  <Button.Template><ControlTemplate TargetType="Button"><Border Background="Transparent"><ContentPresenter/></Border></ControlTemplate></Button.Template>
</Button>
```

處理器的第二個參數要改成 `RoutedEventArgs`：`Click` 不收 `MouseButtonEventArgs` 的處理器。用命令、在 `DataTemplate` 裡的寫法：

```xml
<Button Command="{Binding OpenCommand}" AutomationProperties.Name="{Binding Title}">
  <Button.Template><ControlTemplate TargetType="Button"><Border Background="Transparent"><ContentPresenter/></Border></ControlTemplate></Button.Template>
  <TextBlock Text="{Binding Title}" Style="{StaticResource LinkText}"/>
</Button>
```

原本帶樣式的元素留在 Button 裡面，樣子就不會變；焦點要看得見（上一節）。

## not-in-tab-order

拿掉 `IsTabStop="False"`／`Focusable="False"`，或給同一件事一個快速鍵（`KeyBinding`）、一個 Tab 到得了的控制項。

## focus-not-visible

別動 `FocusVisualStyle`，或在範本裡畫出焦點。

```xml
<!-- 原本 -->
<Setter Property="FocusVisualStyle" Value="{x:Null}"/>
<!-- 改成：ControlTemplate 裡 -->
<Trigger Property="IsKeyboardFocused" Value="True">
  <Setter TargetName="Frame" Property="BorderBrush" Value="{DynamicResource {x:Static SystemColors.HighlightBrushKey}}"/>
</Trigger>
```

## small-target

至少 24 × 24，或旁邊留空間（兩個小目標的中心距離 24）。
